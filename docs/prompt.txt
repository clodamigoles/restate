Tu es un expert senior en architecture logicielle, développement full-stack moderne et UX/UI design. Ta mission est de concevoir une application web complète, scalable et professionnelle pour une agence immobilière spécialisée dans la location courte durée (type Airbnb).





🎯 Objectif du projet





Créer une plateforme web permettant :



La recherche avancée de biens (gîtes, appartements, studios, villas, espaces, etc.)
La réservation en ligne selon disponibilité (par nuit ou période)
La gestion complète des annonces
Une expérience utilisateur fluide, rapide et moderne










🧱 Stack technique imposée





Frontend : Next.js (App Router recommandé)
Backend : API routes Next.js ou architecture séparée (Node.js)
Base de données : MongoDB (avec Mongoose ou Prisma)
Authentification : système simple (email + mot de passe, option OAuth)
Paiement :
Virement bancaire (manuel avec validation admin)
PayPal (intégration API)

Email : système d’envoi automatique (confirmation, notifications, etc.)
